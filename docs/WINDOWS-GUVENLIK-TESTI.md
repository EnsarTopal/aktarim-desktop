# Windows dosya yolu testi

USB ve Wi-Fi junction yarışları GitHub Actions'ın tek kullanımlık Windows sanal makinesinde geçti. Bu koşuda ağ tamamen kapalı değildi; aşağıdaki daha sıkı, ağsız Windows ortamında tekrar doğrulama bekliyor. Böyle bir ortamda kaynak, SDK ve paketleri salt okunur bağlayın; ayrı sınırlı yazılabilir çalışma alanı, boş/izinli değişkenlerden oluşan ortam ve CPU, bellek, süreç, dosya boyutu, disk ve süre sınırları kullanın. Gerçek kullanıcı klasörlerini, kimlik bilgilerini ve paylaşılan dosyaları bağlamayın. Sembolik bağlantı fikstürü için test kullanıcısının uygun Windows yetkisi gerekir.

1. `src/Aktarim.Core` ve `tests/Aktarim.Core.Tests` dizinlerinin ayrı bir kopyasını yazılabilir çalışma alanına, aynı göreli konumları koruyarak alın. Geçici dosyaları ve `LOCALAPPDATA`yı da bu alana yönlendirin. SDK ve varsa NuGet paketlerini önceden yerel olarak sağlayın; ağdan paket indirmeyin.
2. Bu kopyanın kökünden `dotnet restore tests/Aktarim.Core.Tests/Aktarim.Core.Tests.csproj --source <boş-yerel-paket-dizini>` ve ardından `dotnet run --no-restore --project tests/Aktarim.Core.Tests/Aktarim.Core.Tests.csproj` çalıştırın.
3. Sonuçta normal aktarımın özetinin eşleştiğini ve mevcut hedefin korunmasını kontrol eden satırlar ile `transfer directory cannot be replaced during write`, `destination directory cannot be replaced while guarded`, `destination symlink rejected` ve `destination junction rejected` satırlarının tümünün PASS olmasını doğrulayın.
4. Aynı test son yayımlamadan hemen önce ayrı bir süreç başlatır. Bu süreç hedef klasörü taşımayı ve yerine dışarıyı gösteren junction oluşturmayı dener. `separate process attempted junction replacement`, `outside sentinel hash unchanged`, `existing destination hash unchanged` ve başarı durumunda `race output SHA-256 matches` veya ret durumunda `race transfer safely rejected` sonuçlarını kontrol edin.

Eski sürümün hedef altındaki `.aktarim-partial` deposu otomatik taşınmaz. Eski yarım aktarımlar yeni depoda sürdürülmez; eski parçalar kendiliğinden silinmez.
